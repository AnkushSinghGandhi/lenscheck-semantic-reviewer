## How to sign

Code contributions to this repository require agreeing to this CLA **once**. When you open your first
pull request, the CLA-assistant bot will comment with a link and ask you to confirm by replying:

```
I have read the CLA Document and I hereby sign the CLA
```

Your GitHub username and the signing date are recorded in `signatures/cla.json`. That's it — you only
sign once, and it covers all your future contributions.

Prefer not to sign a CLA? **Bug reports, feedback, and documentation issues never require one** — and
if you want to write code without a CLA, the sibling MIT-licensed project
[`lenscheck-contract`](https://github.com/AnkushSinghGandhi/lenscheck-contract) welcomes pull requests
with no agreement needed.
